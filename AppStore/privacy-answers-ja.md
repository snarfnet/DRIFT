# DRIFT App Privacy Notes

DRIFT now uses Google AdMob banner ads.

Before submitting the app for review, update App Store Connect privacy answers for advertising. The app itself does not collect accounts, names, generated music patterns, or contact information.

Suggested items to review in App Store Connect:

- Third-party advertising: Yes
- Data linked to the user: check Google AdMob's current disclosure guidance before final submission
- Data used for tracking: answer Yes only if the app requests tracking or combines data across apps and websites for tracking
- Device ID / advertising identifier: include if AdMob uses it in the selected configuration
- Product interaction, diagnostics, approximate location: include if shown in the AdMob disclosure guidance for the current SDK

Keep the public privacy policy aligned with the final App Store privacy answers.
