# DRIFT

自動テクノ音楽生成アプリ。ドラム、ベース、メロディーを自動で組み合わせて、Paucity (Vince Watson Remix) のようなプロフェッショナルなテクノトラックを生成します。

3つのスタイル：**DRIFT（漂流）** / **DEEP（深層）** / **MINIMAL（最小）**

## 機能

- 🎛️ テンポ調整（80-160 BPM、ディープテクノはデフォルト120BPM）
- 🎯 インテンシティコントロール（0-100%）
- 🎵 キー選択（12キー、C～B）
- 🎵 **スタイル選択**
  - **DRIFT**: Paucity のような漂流的なディープテクノ（長いサステイン、低周波強調）
  - **DEEP**: 深いディープテクノ（複雑で濃密）
  - **MINIMAL**: ミニマルテクノ（シンプルなドラム、ルート音中心）
- 🥁 スタイル対応ドラムパターン生成（808キック、スネア、ハイハット）
- 🎸 スタイル別ベースラインシーケンス（サブベース強調）
- 🎹 スタイル別メロディー生成
- ▶️ リアルタイム再生
- 📊 16ステップパターン可視化
- 🔊 AVAudioEngine ベースのリアルタイム音声合成
- 🎚️ リバーブエフェクト

## アルゴリズム

### ドラムパターン
- **DRIFT**: ミニマルで疎く、長いサステイン感
- **DEEP**: 密集で複雑なポリリズム
- **MINIMAL**: 超シンプルな4on4ビート

### ベースライン
- マイナーペンタトニック + サブハーモニック
- **DRIFT**: サブベース強調（周波数の50%）、2ステップごとに変更
- **DEEP**: 複雑な4ステップパターン、倍音付加
- **MINIMAL**: ルート音とメジャー3度の交互

### メロディー生成
- **DRIFT**: 控えめ（4ステップに1回、intensity > 0.4）
- **DEEP**: 頻繁で変化に富む
- **MINIMAL**: ほぼなし（intensity > 0.6 時のみ、2回）

### オーディオシンセシス
- **キック**: ピッチエンベロープ（減衰するサイン波）
- **スネア**: ホワイトノイズ + ピッチ混合
- **ハイハット**: ハイパスフィルター済みノイズ
- **ベース**: マルチオシレーター（基本波 + サブベース + 3倍音）
- **メロディー**: 複合波形（サイン波 + 微細なノイズ）
- **リバーブ**: Medium Hall プリセット (wet 30%)
